# Curriculum

This directory contains the human-readable source lessons for the E3RC Responsible Artificial Intelligence Certification.

## Planned modules

1. [AI Is a Tool, Not an Authority](01-ai-is-a-tool.md)
2. Verify Before You Trust
3. AI and Schoolwork
4. AI in Engineering and Robotics
5. Teamwork, Credit, and Authorship
6. Bias, Fairness, and Inclusion
7. Privacy, Security, and Confidential Information
8. Deepfakes, Misinformation, and Personal Life
9. Competition, Coopertition, and Community Responsibility
10. Responsible AI Commitment and Final Assessment

## Authoring pattern

Each module should contain:

- Learning objectives
- Approximate completion time
- Reading and/or video segment
- FIRST / Team 1555 connection
- At least one realistic scenario
- Key takeaways
- Knowledge check references
- Sources and update notes

The final student experience may render these lessons through the web app, but Markdown remains the canonical editable curriculum source.
